# Brackenshire: design notes

The game is published as an artifact: https://claude.ai/artifact/2uXu92jFG891PcrbFaXNtW
Always republish to that same URL so Sam's saves carry over (it uses the page's cloud save plus browser storage).

## Sam's choices (from the quiz, 29 Sep 2026)
- **World:** classic countryside mixed with British-inspired places (villages, moors, standing stones, mills, hedgerows).
- **Play style:** a full adventure with a story, plus lots of collecting.
- **Creatures:** cute first forms that evolve into cool ones. **Keep every creature a surprise.** Don't list or describe them outside the game, and keep story twists out of these notes too. Refer to creatures by Journal number only.
- **Starters:** a Fire, Water and Grass trio, all original designs.
- **Look:** like HeartGold/SoulSilver: chunky pixel art, top-down towns, side-view battles. Sam wants it **sharper, cleaner and more polished**, and every Beastie **individually unique** (own face, silhouette, markings), at the level of the official handheld games.
- **Features:** creature follows you, day/night on the real clock (different creatures at night), evolution, rare shinies (about 1 in 200).
- **Difficulty:** classic balance.
- **Story:** 8 badges, a villain team (Team Blight), a legendary tied to the standing stones, then the Elite Four and Champion.
- **Rival:** arrogant (Crispin Ashworth-Vane). **Hero:** Sam. **Saving:** autosave plus manual save. **Device:** computer, keyboard.
- Sam's usage runs out often: **save a checkpoint (project file + republish) after every milestone**, and prefer starting a fresh chat for each new job (long chats cost more per step).
- **Spend no money** on outside tools (4 Oct 2026).

## Status
The whole adventure is built (Chapters 1 to 9, 151 creatures, 8 gyms, 77 maps, Elite Four, Champion, Hall of Fame, post-game).

**Art (4 Oct 2026): the visuals are being redone from a SpriteCook template set. `claude/spritecook-template-set.md` is the up-to-date status, plan and how-to; read it before any art work.** In short: the project build has the new art layer (hero, all people, ground, trees, scenery, common buildings, the three starters); a preview artifact is published for Sam to judge; the main artifact above still has the old look until he approves.

Older code-drawn art (3 Oct): all 151 Beasties were redrawn in code with unique designs; the last 26 (#44-45, #58-61, #105-112, #140-151) never had their final tidy-up. Sam did not like this look, so it is now only the fallback for anything without template art.

## How to change it later
- The playable build is saved in this project as `Brackenshire/brackenshire.html`. It is the source too: the script is one file made of sections, each starting with a `// ---- name ----` comment (engine, render, font, types, creatures, kit, sp1-sp4, dex, art0, art/..., art9, world, ui, battle, maps, maps2, story, story2, main, assets, doll, hd, boot). Split it back into files on those markers, edit, and join them back in the same order. (One comment inside `world` also matches the marker pattern; treat it as its own piece when splitting and the round trip stays exact.)
- Code-drawn creature designs live in the `art/...` sections: `BEAST('id', { pal, keep, sh, draw(g) })`, drawn with the renderer in `render`; guide in `claude/beastie-art-guide.md`. `creatureSprite(id, N, {back, shiny, sil, hd})` is the single entry point for every creature image.
- The `monster-rpg-builder` skill describes the working method (start-up, testing, sprite pipeline, saving). Build and test scripts are saved in `claude/brackenshire-art-tools.md`.
- Chapters 2 to 9 maps (`maps2`) were generated by a Python script; editing the generated section by hand is fine.
